# Praveen Kumar — Portfolio

A responsive, static portfolio website made with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Deploy free with GitHub Pages
1. Create a GitHub repository, for example `praveen-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main`, folder `/ (root)`, then Save.
6. Wait for the published URL shown in Settings → Pages.

You can also deploy the folder using Netlify Drop or import the repository into Vercel.
